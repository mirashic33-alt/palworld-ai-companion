# Мия · голосовой ИИ-напарник для Palworld

*[English version](README.md)*

Живой ИИ-компаньон, который сидит рядом, пока ты играешь в **Palworld**: следит за
событиями игры, реагирует на них голосом с характером, слышит тебя через микрофон,
видит твой экран по горячей клавише и помнит ваши прошлые заходы.

Это не бот-ассистент, который зачитывает лог. Ключевая идея — **динамика, а не
статика**: не модель решает, на что реагировать, а дешёвый код-диспетчер. Он душит
спам, выкидывает протухшие события и отдаёт нейросети только то, что реально стоит
озвучить — короткой пачкой. На каждое событие модель отвечает по-своему, а не шаблоном.

> ⚠️ Неофициальный фанатский проект. Palworld и все игровые названия принадлежат
> Pocketpair, Inc. Проект с игрой никак не связан и ничего в неё не патчит — только
> читает лог событий, который пишет отдельный UE4SS-мод, и озвучивает реакции.

---

## Что умеет

- **Мозг-диспетчер** — фильтрует поток событий: мелкий спам не чаще раза в N секунд,
  протухшее (старше нескольких секунд) не комментируется, всплеск собирается в одну
  пачку. Отдельная «модель мира» держит контекст «сейчас».
- **Голос (рот)** — озвучка через ElevenLabs Flash v2.5 (низкая задержка) или через
  Gemini TTS (тем же ключом, без второго сервиса). Переключается кнопкой на лету.
- **Слух (уши)** — микрофон-рация: держишь клавишу, говоришь → `faster-whisper`
  офлайн распознаёт речь → текст уходит компаньону. Бесплатно и приватно.
- **Зрение (глаза)** — по горячей клавише **F8** снимок экрана уходит отдельной
  vision-модели, и она даёт короткий стратегический разбор обстановки, не тормозя
  реактивную озвучку.
- **Память** — переживает выключение: `memory.json` (диалог и состояние мира),
  `game_map.md` (сжатая «карта игры» от фонового летописца), `game_memory.md`
  (вехи сессий), `знания.md` (база фактов об игре, копится сама из интернета).
- **Два режима характера** — «Кайф» (соло-игра дома, расслабленный тон) и «Свой»
  (чужой сервер с живыми игроками, тёплый и воспитанный тон). Переключается на лету.
- **Живость** — высокая температура + память последних реплик с запретом
  повторяться: на 10 одинаковых событий 10 разных реакций.

## Требования

- **Windows** (озвучка играется через `winsound`, горячие клавиши — под Windows).
- **Python 3.10+**.
- **Palworld** + [UE4SS](https://github.com/UE4SS-RE/RE-UE4SS) — для мода событий.
- Ключ **Google Gemini** (обязательно) и ключ **ElevenLabs** (опционально, для голоса).

### Python-зависимости

```
pip install PySide6 requests faster-whisper sounddevice numpy mss Pillow pyaudio
```

## Установка

### 1. Ключи API

**Gemini (обязательно)** — берётся из переменной окружения. Задай её один раз:

```powershell
setx GEMINI_API_KEY "твой-ключ-от-google-ai-studio"
```

(ключ бесплатно выдаёт [Google AI Studio](https://aistudio.google.com/apikey);
код также понимает `GOOGLE_API_KEY`). После `setx` перезапусти терминал.

**ElevenLabs (опционально, только для голоса ElevenLabs)** — два способа на выбор:
- переменная окружения `ELEVEN_API_KEY`, **или**
- файл `eleven.key` рядом с `config.py` — вписать в него ключ одной строкой.

Без ключа ElevenLabs просто переключи движок озвучки на `gemini` (кнопка в шапке
окна или `TTS_ENGINE = "gemini"` в `config.py`) — он работает тем же ключом Gemini.

### 2. Мод событий MiaEvents

Компаньон читает события из лога, который пишет UE4SS-мод. Скопируй папку
**`MiaEvents`** (лежит в этом репозитории) в папку модов UE4SS:

```
...\steamapps\common\Palworld\Pal\Binaries\Win64\ue4ss\Mods\MiaEvents\
```

Мод должен быть включён (в UE4SS это делается через `mods.txt` либо файлом
`enabled.txt` внутри папки мода — он уже лежит). При игре мод пишет события в
`events.log` в своей папке — этот путь и указан в `config.py` (`LOG_FILE`).

> Путь к логу в `config.py` прописан под стандартную установку Steam. Если Palworld
> у тебя в другом месте — поправь `LOG_FILE` в `config.py` под свой путь.

### 3. Свой игровой ник

В `config.py` укажи `PLAYER_NAME` — твой ник в игровом чате Palworld. По нему
компаньон отличает **твои** сообщения от чужих игроков в мультиплеере.

## Запуск

```
pythonw assistant.pyw
```

(запусти как `python assistant.pyw` — увидишь ошибки в консоли, если что-то не так.)

### Как проверить прямо сейчас, без игры

Внизу окна есть поле ввода — впиши тестовое событие, например
`ПОЙМАН ПАЛ: Гумосс`, и нажми Enter. Компаньон отреагирует. Так видно мозг и голос
без запуска Palworld.

### С игрой

Нажми кнопку **«Игра»**, запусти Palworld с включённым модом MiaEvents — и компаньон
начнёт комментировать всё, что происходит.

## Настройки

Часть параметров крутится **на лету из окна** (кнопка-шестерёнка ⚙): длина реплики,
температура (живость), модель Gemini, движок озвучки, паузы, режим характера.
Меняются без перезапуска и переживают выключение (`settings.json`).

Остальное — в **`config.py`** с подробными комментариями: тайминги диспетчера,
модели для vision/летописца, горячая клавиша скриншота, голоса, цвета темы.

## Структура

| Файл / папка      | Что это                                                            |
|-------------------|-------------------------------------------------------------------|
| `assistant.pyw`   | Окно (PySide6): слежка за логом, микрофон, скриншот, потоки        |
| `brain.py`        | Мозг: диспетчер, модель мира, промпты характера, вызов Gemini      |
| `voice.py`        | Озвучка: ElevenLabs Flash / Gemini TTS                             |
| `screenshot.py`   | Снимок экрана по F8 (mss, с fallback на Pillow)                    |
| `shutter.py`      | Захват звука с микрофона для распознавания                         |
| `config.py`       | Все настройки и константы                                          |
| `знания.md`       | База фактов об игре (копится сама, можно править руками)           |
| `MiaEvents/`      | UE4SS-мод: пишет события игры в `events.log` (Lua)                 |
| `скриншоты/`      | Сюда падают снимки экрана по F8                                    |

Файлы памяти (`memory.json`, `game_map.md`, `game_memory.md`) создаются
автоматически при первом запуске.

---

## Как это устроено (кратко)

1. Мод **MiaEvents** цепляется хуками UE4SS к функциям игры (поимка пала, левелап,
   смерть, чат, босс, сундук…) и пишет их человекочитаемой строкой в `events.log`.
2. `assistant.pyw` следит за хвостом лога, **диспетчер** в `brain.py` фильтрует поток
   и решает, что достойно реакции.
3. Отобранное с промптом-характером уходит в **Gemini**, ответ — в **озвучку**.
4. Параллельно: микрофон (`faster-whisper`) даёт голосовой ввод, F8 — зрение,
   фоновый летописец сжимает лог в «карту игры», всё пишется в память на диск.
